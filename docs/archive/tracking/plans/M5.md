# Milestone M5: Brush Interaction + Hand Cursor (Gate G4) Implementation Plan

## Goal

Implement the tactile meadow brush interaction and stylized organic hand cursor:

1. `GroundRaycaster` for fast analytic terrain intersection with binary refinement.
2. `BrushTrail` ring buffer (16/12/8 per tier) with the exact spring-back impulse response curve $r(\text{age}) = \exp(-2.4 \cdot \text{age}) \cdot \cos(6.0 \cdot \text{age})$ and overshoot clamping.
3. `Pointer` handler unifying mouse, touch, and pen with 3-frame velocity smoothing.
4. `KeyboardBrush` virtual brush driven by arrow keys at 9 m/s ground-space.
5. `HandCursor` custom SVG cursor with open, moving (rotation clamped to $\pm 12^\circ$), and pressed fist states, with 0.35/frame soft position lerp.
6. Grass shader trail uniform updates and `App` loop integration.
7. Unit tests and Playwright E2E verification capturing the brush sweep and spring-back recovery sequence ($t=0, 0.4, 1.0, 2.0, 3.0\text{ s}$).

---

## Tasks Breakdown

1. **Task 5.1: GroundRaycaster (`src/input/GroundRaycaster.ts`)**

   - Ray march from camera through pointer NDC coordinates in 0.5 m steps up to 120 m while `ray.y > terrainHeight`.
   - 6 binary refinement iterations upon crossing into terrain.
   - Zero per-frame memory allocation using cached scratch vectors (`THREE.Vector3`, `THREE.Ray`).
   - Returns `THREE.Vector3 | null` (returns `null` when pointing at the sky).
   - Frame cache to avoid redundant raycasts in a single frame.
   - Unit tests: `tests/unit/ground-raycaster.test.ts`.
   - Commit: `feat(input): implement GroundRaycaster with analytic terrain binary refinement`

2. **Task 5.2: BrushTrail Ring Buffer & Spring Response (`src/world/BrushTrail.ts`)**

   - Ring buffer of trail points with capacity per tier (16 high, 12 medium, 8 low).
   - Point: `{ x, z, radius, strength, age, totalLife }`.
   - `maybePush(hitPoint, speed, cameraPos)`:
     - Push when moved $\ge 0.25\text{ m}$ or $\ge 40\text{ ms}$ since last point, provided $\text{speed} > 0.4\text{ m/s}$.
     - Radius: $\text{clamp}(1.4 + 0.05 \cdot \text{distFromCamera}, 1.4, 3.0)$.
     - Strength: $\text{clamp}(\text{speed} / 6.0, 0.15, 1.0)$.
   - `update(dt)`:
     - Advance point ages.
     - Prune points older than 2.4 s.
   - Response evaluation:
     - $r(\text{age}) = \exp(-2.4 \cdot \text{age}) \cdot \cos(6.0 \cdot \text{age})$.
     - First overshoot ($\text{age} < 1.0\text{ s}$) clamped to $\ge -0.12$ (maximum $-12\%$ overshoot).
     - Subsequent oscillations ($\text{age} \ge 1.0\text{ s}$) clamped to $\ge 0.0$ to decay smoothly without negative jitter.
   - `writeUniforms(targetVectors, countRef)`: zero-allocation copy into `Grass` uniform array `uTrail[16]`.
   - Unit tests: `tests/unit/brush-trail.test.ts`.
   - Commit: `feat(world): implement BrushTrail ring buffer and spring response curve`

3. **Task 5.3: Unified Pointer & KeyboardBrush (`src/input/Pointer.ts`, `src/input/KeyboardBrush.ts`)**

   - `Pointer`:
     - Listen to `pointermove`, `pointerdown`, `pointerup`, `pointercancel`, `pointerleave` on canvas wrapper.
     - Single active `pointerId` tracking; ignore secondary pointers.
     - `touch-action: none` and `contextmenu` prevented on canvas.
     - Normalized screen coordinates $(0..1)$, NDC $(-1..1)$, client coordinates, and deltas.
     - 3-frame rolling velocity smoothing in ground meters/sec.
     - Touch/pen vs mouse distinction.
   - `KeyboardBrush`:
     - Arrow keys move virtual brush at 9 m/s ground-space.
     - Mouse movement overrides virtual brush.
     - Enter triggers tap at virtual brush position.
     - Space key handled for lie down in M6, but ignored when modifier keys (Ctrl/Alt/Meta) are active.
   - Unit tests: `tests/unit/pointer.test.ts`.
   - Commit: `feat(input): implement unified Pointer listener and KeyboardBrush`

4. **Task 5.4: HandCursor SVG & Micro-Interactions (`src/ui/HandCursor.ts`)**

   - Create custom stylized vector SVGs:
     - `open`: relaxed open hand.
     - `moving`: hand with dynamic velocity rotation $\text{clamp}(v_x \cdot 0.02, -12, 12)^\circ$.
     - `pressed`: closed fist grip.
   - Soft position tracking lerping at 0.35/frame towards pointer or virtual brush.
   - Automatic hiding for touch/pen devices or when pointer leaves window.
   - Points at sky: stays `open`, no rotation.
   - Zero external icon assets; self-contained in DOM.
   - Commit: `feat(ui): implement HandCursor with organic motion and SVGs`

5. **Task 5.5: App Loop & Grass Uniforms Integration**

   - Integrate `Pointer`, `GroundRaycaster`, `BrushTrail`, `KeyboardBrush`, and `HandCursor` into `App.ts`.
   - Wire trail uniforms into `Grass.ts` on every tick.
   - Expose debug/testing hooks on `window.__grass`.
   - Commit: `feat(core): wire brush interaction and hand cursor into main loop`

6. **Task 5.6: E2E Playwright Tests & Screenshot Sequence (`tests/e2e/brush.spec.ts`)**

   - Programmatic pointer sweep across meadow.
   - Capture 5 sequential screenshots at $t = 0, 0.4, 1.0, 2.0, 3.0\text{ s}$ illustrating:
     - $t = 0$: active sweep push.
     - $t = 0.4$: maximum spring-back overshoot.
     - $t = 1.0$: settling phase.
     - $t = 2.0$: near-rest decay.
     - $t = 3.0$: complete recovery to resting blades.
   - Validate cursor states (`open`, `moving`, `pressed`).
   - Validate zero console errors and steady frame performance.
   - Commit: `test(e2e): add brush interaction and hand cursor Playwright tests`
