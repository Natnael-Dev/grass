- **Assets & Head Metadata (FR-18):**

- **Security & Privacy Audit (NFR-04, NFR-06, NFR-07):**

  - Dependency audit: run `npm audit --omit=dev` ensuring 0 high/critical vulnerabilities.

  - Cookie & storage assertion: verify 0 cookies set and only designated safe storage keys (`grass_mood`, `grass_muted`, `grass_hints_seen`) are written.
  - Security headers review in `vercel.json` (`Content-Security-Policy`, `X-Content-Type-Options`, `Referrer-Policy`, `Permissions-Policy`).

- **Cross-Browser Verification & E2E Hardening (NFR-04, NFR-08, NFR-09):**

  - Run full E2E Playwright test suite against production preview build.
  - Verify zero console errors or warnings across entire test execution (excluding documented EE-4 debug info).
  - Test browser compatibility matrix across Chromium, Firefox, and WebKit where available.

- **Anti-AI-Slop & Multi-Lens Architectural Review:**

  - Audit codebase for any dead code, placeholder UI, fake interactivity, commented-out code, and unreferenced exports.
  - Verify strict adherence to code standards: zero `TODO` or `FIXME` comments in `src/`.
  - Verify pure logic isolation, module sizing, and zero per-frame hot path allocations.

- **Full Traceability Matrix (`tracking/TRACEABILITY.md`):**

  - Resolve every requirement row (FR-01 through FR-20, NFR-01 through NFR-10) with verified evidence paths and commit SHAs.
  - Update docs-vs-code consistency across design, architecture, and frontend specifications.

- **Evidence & Gate G11 Sign-Off:**

  - Verify `npm run check` passes with 0 lint warnings, 0 type errors, 100% passing tests, and size budgets satisfied.
