## 1. Objectives & Scope

- **UI Shell & Tokens:** CSS custom properties matching `design-system.md`, glassmorphism panels, responsive layouts, safe area insets.
- **Copy Single Source of Truth:** `src/ui/copy.ts` matching `docs/01-design/copywriting.md` verbatim.
- **HUD Components:**
  - `Wordmark`: `grass_` with blinking underscore (static under reduced motion).
  - `MoodSwitch`: Dawn, Golden, Night pill buttons with SVG icons, `aria-pressed`, title keyboard hints (1, 2, 3).
  - `SoundToggle`: Speaker icon pill button with `aria-label="sound on"|"sound off"` (UI only; Web Audio wired in M9).
  - `HowItWorksButton`: `how it works` pill button with SVG question mark icon (`aria-label="how it works, help"`).
  - `Uptime`: 1 Hz counter (`uptime outside: mm:ss`), paused on tab hidden or app pause.
  - `Hud`: Activity fade (opacity 1.0 -> 0.45 after 4 s pointer activity, restored on pointer leave or focus).
- **Hint System:**
  - `HintLine`: Typed text at 28 ms/char (`role="status" aria-live="polite"`), held 6 s, 400 ms fade.
  - `HintSequencer`: First-visit sequence (+1.5s -> hint 1; brush >= 600px or +8s -> hint 2; tap or +8s -> hint 3; holdEnd or +12s -> hint 4).
  - Persistence via `grass:hints-seen`. Skipped for returning visitors.
- **Modal Dialog:** `HowItWorks`
  - `role="dialog"`, `aria-modal="true"`, focus trap, Esc to close, return focus to opener.
  - Controls table, Q&A, open source credits, close button.
- **Easter Eggs (`src/easter/eggs.ts`):**
  - EE-1: `exit` typing buffer -> terminal `ExitScreen` with `[ re-run ]` button.
  - EE-2: 10 s lie-down hold hint: `> fatal: no merge conflicts in this meadow.`.
  - EE-3: Uptime announcements at 03:00 and 10:00.
  - EE-4: Console greeting with ASCII blade (verified).
- **Persistence & Fallbacks:**
  - `src/core/storage.ts`: Safe `localStorage` wrapper handling private mode / exceptions.
  - `404.html`: Static 404 page matching design tokens and copywriting.
- **Verification:**
  - Unit tests for copy, storage, hint sequencer, eggs, uptime.
  - Playwright E2E tests for J1, J2, J4, dialog focus trap, Easter eggs, 404 page, and UI state screenshots.
