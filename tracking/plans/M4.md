# Milestone M4: Mood System (Gate G3) Implementation Plan

## Goal

Implement the three atmospheric mood presets (`dawn`, `golden`, `night`) with a retargetable 2.5s ease-in-out crossfade, linear-sRGB color interpolation, spherical arc disc path, moon/sun disc rendering, and dev keybindings (`1`, `2`, `3`).

## Tasks Breakdown

1. **Task 4.1: Mood Presets Data (`src/world/moods.ts`)**

   - Define `MoodPreset` interface per `design-system.md` and `state-and-ui-components.md`.
   - Exact values for `dawn`, `golden`, `night` directly from the `design-system.md` table.
   - Time-of-day helper `getDefaultMood(date?: Date, storedMood?: MoodName | null): MoodName`:
     - 05:00-09:59 -> `dawn`
     - 10:00-18:59 -> `golden`
     - else -> `night`
   - Unit tests: `tests/unit/moods.test.ts` asserting exact equality with doc table and time-of-day ranges.
   - Commit: `feat(world): add mood presets and time-of-day default logic`

2. **Task 4.2: MoodController (`src/world/MoodController.ts`)**

   - Retargetable crossfade over 2.5s using `easeInOut` (`smoothstep` curve).
   - Zero-allocation hot path: preallocated `THREE.Color` and `THREE.Vector3` objects on `MoodState`.
   - Lerp colors in linear-sRGB.
   - Lerp disc position via `elevationDeg` and `azimuthDeg` spherical angles so it travels in a natural arc.
   - Compute `discDir` and `sunDir` dynamically from spherical coordinates.
   - Unit tests: `tests/unit/mood-controller.test.ts` testing monotonicity, mid-fade retargeting without pops, and completion to exact preset target.
   - Commit: `feat(world): implement MoodController with retargetable crossfade and arc disc math`

3. **Task 4.3: Moon/Sun Shader Variants & Stars Tuning (`src/world/shaders/sky.frag.glsl`)**

   - Add moon disc surface mottling at night via subtle procedural noise (no bitmaps).
   - Twinkling star field masked by horizon and driven by `uStarsAmount`.
   - Commit: `feat(sky): add procedural moon mottling and stars crossfade`

4. **Task 4.4: System Uniforms Wiring**

   - Wire `Sky` to consume `MoodState` (`skyTop`, `skyMid`, `skyHorizon`, `discColor`, `discDir`, `discSize`, `discHalo`, `cloudColor`, `cloudCover`, `starsAmount`, `fogColor`).
   - Wire `TerrainMesh` to consume `MoodState` (`uTerrainColor`, `uLightColor`, `uLightIntensity`, `uAmbientColor`, `uAmbientIntensity`, `uSunDir`, `uFogColor`, `uFogDensity`).
   - Wire `Grass` to consume `MoodState` (`uGrassBase`, `uGrassTip`, `uLightColor`, `uLightIntensity`, `uAmbientColor`, `uAmbientIntensity`, `uSunDir`, `uFogColor`, `uFogDensity`, `uWindStrength`).
   - Wire `Ridges` to consume `MoodState` (`uColor1`, `uColor2`, `uColor3`, `uFogColor`, `uFogDensity`).
   - Wire `Tree` to consume `MoodState` (`uLightColor`, `uLightIntensity`, `uAmbientColor`, `uAmbientIntensity`, `uSunDir`, `uFogColor`, `uFogDensity`).
   - Commit: `feat(world): wire MoodState to Sky, Terrain, Grass, Ridges, and Tree systems`

5. **Task 4.5: App Integration & Keyboard Controls**

   - Instantiate `MoodController` in `App.ts`.
   - Wire `?mood=` URL flag and store mood sync.
   - Add dev keyboard listener for keys `1` (dawn), `2` (golden), `3` (night).
   - Update `window.__grass.setMood` to trigger smooth crossfade.
   - Commit: `feat(app): integrate MoodController into App loop with dev keybindings`

6. **Task 4.6: E2E Verification & Visual Review (`tests/e2e/moods.spec.ts`)**

   - Assert crossfade sampling is monotonic and smooth over 2.5s.
   - Assert mid-fade retargeting works seamlessly without visual discontinuity.
   - Capture 3 golden evidence screenshots:
     - `tracking/evidence/M4/mood-dawn.png`
     - `tracking/evidence/M4/mood-golden.png`
     - `tracking/evidence/M4/mood-night.png`
   - Visual inspection of all 3 images with `view_file` tool against art direction quality bar.
   - Commit: `test(e2e): add mood crossfade verification and capture mood evidence screenshots`

7. **Task 4.7: Gate G3 Verification & Evidence**
   - Run `npm run check`.
   - Write `tracking/evidence/M4/README.md`.
   - Update `tracking/PROGRESS.md`.
   - Commit locally: `chore(tracking): complete milestone M4 automated gate and evidence`.
   - Present Human Test Request for Gate G3 and pause.
