## 1. Objectives & Scope

- **Adaptive Quality Controller (`src/core/AdaptiveQuality.ts`):**

  - Rolling window of frame intervals (120 frames).
  - Metrics tracking: rolling average FPS, p95 frame time, and frame-time variance/stddev.
  - Warm-up period (3.0 seconds / 180 frames) to allow initial asset compile/JIT stabilization without false down-tiering.
  - Hysteresis-backed down-tiering: when rolling average FPS < 45 (or p95 > 22.2 ms), trigger step down (`high` -> `medium` -> `low`).
  - Up-tiering at sustained stable 60 FPS: when rolling average FPS >= 58 with low variance over sustained window without drops, step up (`low` -> `medium` -> `high`).
  - Cooldown timer (4.0 seconds) between tier transitions to eliminate thrashing.
  - Manual override support: respect explicit URL query parameter `?quality=` or user preference (`isLocked: boolean`), disabling autonomous tier shifts.
  - Comprehensive unit test suite (`tests/unit/adaptive-quality.spec.ts`) with synthetic frame sequences.

- **System Integration (`src/app/App.ts`, `src/core/Renderer.ts`):**

  - Integrate `AdaptiveQuality` into the main rendering loop in `App.ts`.
  - Wire tier changes across subsystems:
    - `Grass`: instanceCount (90k -> 45k -> 18k), LOD blade segments, and density compensation (`uDensityComp`).
    - `BrushTrail`: capacity (16 -> 12 -> 8).
    - `Fireflies`: active count (90 -> 60 -> 30).
    - `Seeds`: spawn count per tap (18 -> 14 -> 10).
    - `Renderer`: DPR cap adjustments (high: 2.0, medium: 1.5, low: 1.25).
  - Expose `adaptiveQuality` API on `window.__grass` for profiling, test automation, and synthetic frame injection.

- **Hot-Path & Memory Allocation Audit:**

  - Verify zero per-frame garbage collection pressure in rAF hot paths.
  - Verify scratch objects (`Vector3`, `Vector4`, `Color`, matrix buffers) are reused across pointer, raycasting, camera, and trail systems.
  - Comprehensive dispose audit ensuring no dangling event listeners, textures, or geometry buffers.

- **Playwright E2E Performance Benchmark Suite (`tests/e2e/perf.spec.ts`):**

  - Verify baseline 60 FPS frame-time budget.
  - Verify draw call budget: total scene draw calls <= 12 (grass = 1).
  - Verify triangle budget: <= 500k triangles on medium tier (and adherence to tier-specific limits).
  - Verify bounded memory growth over sustained interactions.
  - Verify adaptive quality downgrade when artificial frame delays are simulated.
  - Verify manual override `?quality=` prevents auto-tiering.

- **Evidence & Gate G10 Sign-Off:**
  - Record empirical measurements, draw calls, triangles, memory growth, bundle size, and synthetic benchmark logs in `tracking/evidence/M11/README.md`.
  - Verify full `npm run check` passes with zero errors and zero warnings.
  - Stop at Gate G10 for human verification.
