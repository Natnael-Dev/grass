# Milestone M2 Plan: Render Core (G1)

**Purpose:** Implement the 3D rendering core: analytic terrain function (`terrainHeight`), deterministic PRNG, WebGL2 Renderer with DPR caps, render Loop with delta time clamp and tab visibility pause, base CameraRig pose, procedural gradient Sky with sun disc and clouds, layered mountain Ridges, low-poly silhouette Tree on hill crest, and debug stats overlay.

## Requirements Covered

- **FR-02 World:** Analytic terrain (`terrainHeight(x,z)`), gradient sky dome with sun disc, clouds, 2–3 distant ridge silhouettes, one lone tree on the hill crest.
- **FR-19 Visibility:** Rendering pauses when tab is hidden; time delta clamps to 0.1s so no jump on resume.

---

## Tasks & Planned Atomic Commits

1. **Task 2.1: Deterministic PRNG (`src/core/prng.ts`)**

   - Seeded mulberry32 / splitmix32 PRNG for reproducible world and grass generation.
   - Methods: `random()`, `range(min, max)`, `gaussian()`, `choice(arr)`.
   - Unit tests in `tests/unit/prng.test.ts`.
   - Commit: `feat(core): add deterministic PRNG with unit tests`

2. **Task 2.2: Analytic Terrain Function (`src/world/terrain.ts`)**

   - Implement `terrainHeight(x, z)` matching specification: main hill with tree at `(6, -26)`, secondary rise at `(-30, -40)`, gentle swell, and flat foreground near camera (`z > -4`).
   - Implement `terrainNormal(x, z, eps)` via central differences.
   - Unit tests in `tests/unit/terrain.test.ts` (determinism, bounds, continuity, tree crest height).
   - Commit: `feat(world): add analytic terrainHeight function and normal generator with unit tests`

3. **Task 2.3: WebGL2 Renderer & Frame Loop (`src/core/Renderer.ts`, `src/core/Loop.ts`)**

   - `Renderer`: Three.js WebGLRenderer with sRGBColorSpace, DPR capping per tier, resize observer.
   - `Loop`: requestAnimationFrame runner, clamped delta time (`dt <= 0.1s`), page visibility listener (`document.visibilityState`) that pauses rendering and prevents delta spikes on resume.
   - Unit tests in `tests/unit/loop.test.ts`.
   - Commit: `feat(core): implement WebGL2 Renderer and rAF Loop with visibility pause and dt clamping`

4. **Task 2.4: CameraRig Vista Pose & Ground Clearance Clamp (`src/camera/CameraRig.ts`)**

   - `CameraRig`: PerspectiveCamera with landscape FOV 48° / portrait 55°, base position `(0, terrainHeight(0,10)+1.65, 10)`, look-at `(0, 2.4, -22)`, ground clearance clamp (`y >= terrainHeight + 0.25`).
   - Unit tests in `tests/unit/camera.test.ts`.
   - Commit: `feat(camera): implement CameraRig with base vista pose and ground clearance clamp`

5. **Task 2.5: Procedural Sky Dome Shader (`src/world/Sky.ts`, shaders)**

   - Inverted dome geometry (radius 400, depthWrite=false, renderOrder -10).
   - Custom `ShaderMaterial` with 3-stop vertical gradient (top, mid, horizon), glowing sun disc with soft halo, and 3-octave procedural drifting clouds (golden mood preset).
   - Commit: `feat(world): add procedural gradient Sky shader with sun disc and clouds`

6. **Task 2.6: Terrain Mesh & Layered Mountain Ridges (`src/world/Terrain.ts`, `src/world/Ridges.ts`)**

   - `Terrain`: PlaneGeometry 160×160 with 128×128 subdivisions, vertex Y assigned from `terrainHeight(x, z)`, vertex normals calculated from central differences, custom/standard material with ground color and fog.
   - `Ridges`: 3 layered silhouette ribbons at `z = -160, -230, -310` with noisy crests, fog-blended into the horizon.
   - Shared exponential fog chunk (`fog.glsl`).
   - Commit: `feat(world): add Terrain mesh and layered Ridges with fog integration`

7. **Task 2.7: Low-Poly Silhouette Tree (`src/world/Tree.ts`)**

   - Low-poly stylized tree placed at `(6, terrainHeight(6, -26), -26)`.
   - Tapered trunk + 6 merged foliage icospheres with vertex-colored soft gradient.
   - Gentle wind sway vertex offset.
   - Commit: `feat(world): add low-poly silhouette Tree on hill crest`

8. **Task 2.8: App Integration, Store, Capabilities Check, & Debug Stats Overlay**

   - `src/app/store.ts`: typed observable application store.
   - `src/app/flags.ts`: parse `?quality=`, `?debug=`, `?freeze=`, `?seed=`.
   - `src/app/capabilities.ts`: WebGL2 check with graceful Fallback hook.
   - `src/debug/StatsOverlay.ts`: lightweight canvas/DOM debug overlay showing FPS, tier, draw calls, and triangle counts.
   - `src/app/App.ts`: assemble Loop, Renderer, CameraRig, World, and UI.
   - `src/main.ts`: boot sequence and `window.__grass` test hooks.
   - Commit: `feat(core): add app state store, URL flags, capabilities check, and debug stats overlay`

9. **Task 2.9: E2E Verification & Visual Review**

   - `tests/e2e/rendercore.spec.ts`: test scene boot, canvas non-blank verification, tab visibility pause test, resize test, draw call assertion (< 10 draw calls), and golden vista screenshot capture.
