# Milestone M6: Lie-Down, Parallax, and Idle (Gate G5) Implementation Plan

## Goal

Implement the immersive lie-down perspective, organic camera parallax, and ambient idle behaviors:

1. `GestureClassifier` with micro-interaction state machine (idle -> pressing -> dragging / holding / tap).
2. Exact boundary thresholds: 250 ms hold, 8 px drag radius, clean cancel on pointercancel/blur/visibilitychange.
3. Space key hold support (preventing scroll, ignoring repeats and modifiers).
4. `CameraRig` state polish:
   - Lying dip pose: camera y $\to \text{terrainHeight} + 0.38\text{ m}$, pitch $+14^\circ$, FOV $+4^\circ$, 1.1 s ease-out entry, 0.9 s ease-in-out exit.
   - Reduced motion mode: 300 ms linear move, 0 FOV change, 0 vignette change.
   - Parallax doubling ($\pm 12^\circ$ yaw, $\pm 6^\circ$ pitch) during lie-down.
   - Idle drift ($\pm 1.5^\circ$ yaw at 0.04 Hz) triggered at 25 s inactivity with 5 s wind gust ($\times 1.6$).
   - Ground clamp: camera $y \ge \text{terrainHeight} + 0.25\text{ m}$ at all times.
5. Vignette overlay (+0.25 in lie-down) and HUD dimming (opacity $\to 0.35$).
6. Hand cursor pressed state during hold, auto-hiding after 1.0 s.
7. EE-2 hook point at 10 s continuous hold.
8. Unit tests (classifier boundaries, camera states) and Playwright E2E tests (standing vs lying screenshots, camera height verification, 5 terrain clearance samples, idle trigger).

---

## Tasks Breakdown

1. **Task 6.1: GestureClassifier (`src/input/GestureClassifier.ts`)**

   - Implement state machine: `idle`, `pressing`, `dragging`, `holding`.
   - Thresholds: 250 ms hold timer, 8 px max displacement.
   - Events emitted: `tap`, `holdStart`, `holdEnd`, `ee2Trigger` (at 10 s continuous hold).
   - Key bindings: Space key hold with key repeat suppression and modifier key check.
   - Cancellation: `pointercancel`, `pointerleave` if captured, `window.blur`, `visibilitychange`.
   - Unit tests: `tests/unit/gesture-classifier.test.ts`.
   - Commit: `feat(input): implement GestureClassifier with tap, hold, and boundary logic`

2. **Task 6.2: CameraRig Polish (`src/camera/CameraRig.ts`)**

   - Precise 1.1 s `--ease-out` dip entry and 0.9 s `--ease-inout` recovery.
   - Parallax doubling when lying (`isLying = true`).
   - Idle drift: 0.04 Hz sinusoidal yaw $\pm 1.5^\circ$.
   - Idle gust factor hook for wind.
   - Ground clamp verification: $y = \max(y, \text{terrainHeight} + 0.25)$.
   - Reduced motion support: 300 ms linear transition without FOV alteration.
   - Unit tests: `tests/unit/camera-rig.test.ts`.
   - Commit: `feat(camera): implement dip pose, doubled parallax, idle drift, and reduced motion in CameraRig`

3. **Task 6.3: Vignette Overlay & HUD Lie-Down Dimming (`src/ui/Vignette.ts`, CSS)**
