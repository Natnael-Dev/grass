# Milestone M3 Plan: Grass Instancing & Wind (Gate G2)

**Purpose:** Implement single-draw-call GPU grass instancing (90,000 / 45,000 / 18,000 blades), dual-octave wind noise texture and vertex flutter, distance-weighted density rings, Fisher-Yates instance shuffle for uniform thinning, custom grass GLSL shader with back-light translucency, root AO, rim lighting, atmospheric fog, and quality tier flag (`?quality=`).

## Requirements Covered

- **FR-03 Grass System:** Single draw call instancing, blade geometry LOD (4/3/2 segments), seeded PRNG placement, distance density weighting (near 55% / mid 35% / far 10%), dual-octave wind waves, root AO, back-light, rim, terrain color matching.

---

## Tasks & Planned Atomic Commits

1. **Task 3.1: Blade Geometry Generator (`src/world/grassGeometry.ts`)**

   - Segment counts: High=4, Medium=3, Low=2.
   - Vertices at heights $t = i/S$, width taper $w(t) = 0.5 \cdot (1 - t^{1.4} \cdot 0.92)$.
   - Tip vertex collapses at top.
   - Double-sided indexed triangles.
   - Unit tests: `tests/unit/grass-geometry.test.ts`.
   - Commit: `feat(grass): create tapered blade geometry generator with LOD segments`

2. **Task 3.2: Wind Noise DataTexture Generator (`src/world/noise.ts`)**

   - 256×256 repeating DataTexture with dual noise octaves:
     - R: Low-frequency traveling gusts (0.012 spatial scale, 0.025 speed).
     - G: High-frequency rapid flutter (0.09 spatial scale, 0.35 speed).
   - Unit tests: `tests/unit/noise.test.ts`.
   - Commit: `feat(grass): generate dual-octave wind noise DataTexture`

3. **Task 3.3: Seeded Grass Instance Generator (`src/world/grassGenerator.ts`)**

   - PRNG placement in area $x \in [-60, 60], z \in [-70, 22]$.
   - Distance weighting from camera base $(0, 10)$: near $r < 14$ (55%), mid $14 \le r < 32$ (35%), far $32 \le r \le 70$ (10%).
   - Attributes: offset $(x, y, z)$, params $(h, w, \text{yaw}, \text{bend})$, rand $(r_1, r_2)$.
   - Full capacity: 90,000 instances.
   - Fisher–Yates shuffle so reducing count thins uniformly without spatial holes.
   - Unit tests: `tests/unit/grass-generator.test.ts`.
   - Commit: `feat(grass): generate seeded density-ring grass instances with Fisher-Yates shuffle`

4. **Task 3.4: Custom Grass GLSL Shaders (`src/world/shaders/grass.vert.glsl`, `grass.frag.glsl`)**

   - Vertex: blade shape, yaw matrix, static lean, dual-noise wind deflection along $t^2$, near-camera dither fade.
   - Fragment: root→tip gradient, patch color variation, per-blade hue jitter, root AO, back-light translucency, rim light, ambient + wrap diffuse, exp2 fog.
   - Commit: `feat(grass): implement custom GLSL grass shaders with wind, AO, rim, and fog`

5. **Task 3.5: Grass System Assembly (`src/world/Grass.ts`)**

   - `InstancedBufferGeometry` single mesh.
   - Dynamic tier switching (`instanceCount = 90k / 45k / 18k`).
   - Width compensation `uDensityComp = sqrt(fullCount / count)` to maintain visual meadow density.
   - Unit tests: `tests/unit/grass-system.test.ts`.
   - Commit: `feat(grass): create Grass system with single-draw-call instancing and tier LOD`

6. **Task 3.6: App Integration, Tier URL Flag, & Terrain Blending**

   - Add Grass to `App` scene graph and render loop.
   - Wire `?quality=low|medium|high` to select blade count and geometry LOD.
   - Expose blade count in `window.__grass.stats()` and `StatsOverlay`.
   - Tune terrain material to match grass root color seamlessly.
   - Commit: `feat(app): integrate Grass into App loop with tier switching and terrain blending`
